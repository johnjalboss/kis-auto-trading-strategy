1. 🌟 시스템 소개 및 핵심 특징
================================================================================
본 시스템은 한국투자증권(KIS) 공식 OpenAPI와 미국 연방준비제도(FRED), 구글 인공지능(Gemini AI),
SEC 공시(13F/Form 4), CBOE 옵션, 다크풀(ATS) 데이터를 실시간 융합하여 미국 주식 3,002개 전 종목 중
가장 확실한 1등 주도주만 선별 자동 매매하는 인공지능 퀀트 트레이딩 머신입니다.

✨ 핵심 특장점
- 24시간 완전 자율 무인 매매: 종목 스캔 -> 5대 팩터 채점 -> 켈리 비중 계산 -> 자동 매수/익절/손절
- 초보자 맞춤형 GUI 설정 마법사: 코드 수정 없이 화면에서 키만 넣고 클릭으로 설정 완료
- 스마트폰 텔레그램 원클릭 제어: PC 없이 스마트폰 버튼으로 잔고/수익률/추천종목 확인 및 긴급 청산
- 월가 헤지펀드급 5대 직교 팩터: 칼만 필터 제로랙 + OFI 오더플로우 + PEAD 어닝 + 13F 다크풀 + 거시경제
- 철저한 원금 보존 6중 안전장치: 단일 종목 손절(-3.8%), 본절 스탑 Lock, 주간 손실 한도(-15%), MDD 서킷브레이커(-25%)

3. 🔑 필수 & 선택 API 발급 A to Z 가이드
================================================================================

3.1 한국투자증권(KIS) OpenAPI 발급 (실전/모의)
1. 한국투자증권 앱에서 해외주식 거래가 가능한 종합 위탁계좌를 개설합니다.
2. KIS Developers (https://apiportal.koreainvestment.com/) 에 접속하여 로그인합니다.
3. 상단 [API 신청/계약] 메뉴에서 서비스 신청 후 App Key와 App Secret을 발급받아 메모합니다.
4. 본인의 종합계좌번호 앞 8자리(CANO)와 뒤 2자리(01)를 확인합니다.
5. 모의투자 테스트를 원하시면 [모의투자 신청] 메뉴에서 모의투자용 키를 추가 발급받으시면 됩니다.

3.2 텔레그램 알림봇 & 채팅 ID 발급 (1분 소요)
1. 텔레그램 앱 검색창에 @BotFather 검색 -> /start -> /newbot 입력 -> 봇 이름/아이디 생성.
2. 발급되는 HTTP API Token (예: 7888401155:AA...) 복사.
3. 텔레그램에 @userinfobot 검색 후 메시지를 보내 내 고유 Chat ID 숫자(예: 6807414163) 확인.
4. 내가 만든 봇 대화방 링크를 누르고 들어가 [시작] 버튼을 클릭해 둡니다.

3.3 구글 제미나이(Google Gemini AI) API 키 발급 (100% 무료)
1. Google AI Studio (https://aistudio.google.com/) 접속 -> 구글 로그인.
2. [Get API key] -> [Create API key] 클릭 -> 생성된 키(AIzaSy...) 복사.
3. GUI 마법사의 Gemini API Key 칸에 붙여넣습니다.

3.4 Finnhub & FRED 거시경제 API 키 발급 (권장)
- Finnhub (기업 실적/내부자): https://finnhub.io/ 회원가입 -> 대시보드 API Key 복사.
- FRED (연준 거시경제): https://fred.stlouisfed.org/ 회원가입 -> My Account -> API Keys 발급.

9. 💎 실전 퀀트 투자 운용 수칙 & 십계명
================================================================================
1. 기계를 믿고 개입을 최소화하세요: 현금 100% 대기는 하락장을 피하는 최고의 투자 전략입니다.
2. 손익비(Profit Factor)의 힘: 질 때 -3%로 짧게 끊고 이길 때 +8~15%로 길게 가져갑니다.
3. 물타기와 몰빵 금지: 1종목에 30~35% 이상 배팅하지 않으며, 추가 매수를 하지 않습니다.
4. 1차 목표가 도달 시 50% 분할 익절: +7.5%~+9.0%에서 절반 익절 후 본절 스탑 유지.

Q1. KIS 인증 토큰은 매일 다시 발급받아야 하나요?

-> 봇이 미국 증시 캘린더를 스스로 체크하여 휴장일에는 자동 대기하고, 서머타임 적용 시 개장 시간에 맞춰 자동 조절합니다.

Q3. 텔레그램 버튼을 눌렀는데 반응이 없어요.
-> 1. 봇 대화방에서 /start를 먼저 전송해 권한을 활성화했는지 확인하세요.
   2. '봇현황.bat'을 더블클릭하여 봇 프로세스가 실행 중인지 확인하세요.

Q4. 모의투자와 실전투자는 어떻게 전환하나요?
-> '설정마법사_GUI.bat'에서 모의투자(Sandbox) 체크박스를 체크/해제 후 저장하시면 됩니다.
