========================================================================
🚀 AI 퀀트 스윙 트레이딩 봇 v2.0 통합 가이드 (내PC & 오라클 VPS 24시간 무인 세팅)
========================================================================

지인분들을 위한 미국 주식 무인 자동매매 프로그램 종합 사용설명서입니다.
내 PC에서 바로 돌리거나, 오라클 클라우드(Oracle VPS) 24시간 무인 서버 구축법이 수록되어 있습니다.

------------------------------------------------------------------------
📌 1. 필수 준비물
------------------------------------------------------------------------
1. 한국투자증권 해외주식 API (AppKey, AppSecret, 계좌번호 8자리)
2. 파이썬 3.10 이상 설치 (윈도우 설치 시 'Add Python to PATH' 체크 필수)

------------------------------------------------------------------------
⚙️ 2. 3분 기본 환경설정 (내 PC / VPS 공통)
------------------------------------------------------------------------
1) 폴더 내 '.env.example' 파일명을 '.env' 로 변경합니다.
2) '.env' 파일을 메모장으로 열고 본인의 API Key 정보를 입력 후 저장합니다.

   [입력 예시]
   KIS_APP_KEY=본인의 AppKey 입력
   KIS_APP_SECRET=본인의 AppSecret 입력
   CANO=계좌번호 8자리 입력
   ACNT_PRDT_CD=01

   (선택) 텔레그램 실시간 매매 알림을 원하시면 텔레그램 봇 토큰과 채팅 ID를 입력합니다.
   TELEGRAM_BOT_TOKEN=본인_토큰
   TELEGRAM_CHAT_ID=본인_ID

3) 명령 프롬프트(CMD) / 터미널에서 필수 라이브러리를 설치합니다:
   pip install -r requirements.txt

------------------------------------------------------------------------
🖥️ 3. 내 PC에서 실행하는 방법
------------------------------------------------------------------------
- 윈도우: 폴더 내 'start.bat' 파일 더블클릭!
- 터미널: python main.py 실행!

------------------------------------------------------------------------
☁️ 4. 오라클 클라우드 (Oracle Cloud) 24시간 무중단 서버 구축법
------------------------------------------------------------------------
컴퓨터를 켜두지 않고 24시간 클라우드에서 무인 구동하고 싶다면 오라클 평생무료 VPS를 사용합니다.

[1단계: 오라클 클라우드 무료 인스턴스 생성]
1. Oracle Cloud (https://www.oracle.com/cloud/free/) 가입.
2. 컴퓨트 인스턴스 생성 -> OS: Ubuntu 22.04 LTS 선택.
3. SSH 전용키(PrivateKey, SSH Key)를 PC에 다운로드 보관합니다.

[2단계: 오라클 VPS 접속 및 파이썬 환경 구축]
1. SSH 접속 (명령 프롬프트 / Terminal):
   ssh -i ssh_key.key ubuntu@<본인_VPS_IP주소>

2. 파이썬 및 필수 패키지 설치:
   sudo apt update && sudo apt install -y python3-pip python3-venv git
   mkdir -p kis-auto-trading && cd kis-auto-trading

3. 프로그램 파일 업로드 후 가상환경 구축:
   python3 -m venv venv
   ./venv/bin/pip install -r requirements.txt

4. .env 파일 생성 및 본인 API 키 입력:
   nano .env   (내용 입력 후 Ctrl+O -> Enter -> Ctrl+X 저장)

[3단계: 24시간 무중단 자동 감시 및 다운 방지 등록 (Crontab)]
봇이 다운되거나 서버가 재부팅되어도 자동으로 켜지도록 크론탭 감시를 등록합니다:

1. crontab -e 명령 실행 후 제일 아랫줄에 다음 한 줄 추가:
   * * * * * pgrep -f main.py > /dev/null || /home/ubuntu/kis-auto-trading/venv/bin/python /home/ubuntu/kis-auto-trading/main.py >> /home/ubuntu/kis-auto-trading/logs/cron.log 2>&1

2. 저장 후 닫으면, 오라클 서버가 24시간 매분마다 봇을 감시하여 죽지 않고 무인 구동됩니다.

------------------------------------------------------------------------
💡 5. 원격 무인 자동 업데이트 안내
------------------------------------------------------------------------
- 내 PC에서 켜든, 오라클 VPS 서버에서 24시간 돌리든 **프로그램 부팅 시 원격 깃허브에서 최신 퀀트 전략을 자동으로 감지하여 덮어쓰기 무인 패치**합니다.
- 사용자는 별도로 업데이트를 신경 쓸 필요 없이 편하게 가동하시면 됩니다.
